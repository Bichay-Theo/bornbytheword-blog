Lɛahd Aqdim akk-d yimeslayen n usebbel deg wemkan-nneɣ akk-d ufdu ↩

M'ara neɣreḍ Lɛahd Ajdid, a naf ṛṛusul heddṛen-d ɣef wumidag s yimeslayen am "ufdu", "asebbel deg wemkan-nneɣ", "uzki", ur aɣ-ilaq ara a nettu yiwet n tideț meqqṛen: ṛṛusul-agi d udayen i llan. Ulawen-nsen ččuṛen d lmeɛnat n Lɛahd Aqdim akk-d lqanun-is, d wagi i d lqesd n Sidi Ṛebbi; axaṭer Sidi Ṛebbi, s yimeslayen d lɛaddat d lqanun n Lɛahd Aqdim, yella iheggi axemmem n wemdan iwakken ad iqbel Bab n ufdu ara d-yasen. Ihi, ma nebɣa ad nefhem s tideț d acu i qesden Bulus d Buṭrus m'ara d-hedṛen ɣef "ufdu", ur nezmir ara a netkel ɣef yimawalen n tmeslayt tagrikit kan, lameɛna ilaq a nuɣal ɣer yiẓuṛan n yimeslayen-agi di Lɛahd Aqdim.

Deg tektabt-is "Abeccer n Ṛṛusul s Wumidag" (The Apostolic Preaching of the Cross), yellan d yiwet si tektabin timeqqranin i gsefhamen lqesd n ufdu, amusnaw n tesnillawit "Lyun Muris" (Leon Morris) isbeggen-d belli imeslayen n leslak ur llin ara d lemtul n tmeslayt kan, lameɛna d imeslayen n lqanun d tesnillawit yesɛan lmeɛna lqayen yettwexḍan di "wazal yettwaxellṣen" s ɣuṛ "ubdil n lqanun".

"Bab n ufdu" (Go'el) akk-d lqanun n ufdu ↩

Awal aɛibri (Gu'il - Go'el) d yiwen seg yimeslayen yesɛan azal ameqqran di Lɛahd Aqdim, yerna yettutṛujem s umata ɣer "Bab n ufdu" neɣ "Amsellek". Awal-agi icudd aṭas ɣer "lqanun n ufdu". Di lqanun n Lɛahd Aqdim (Iwiyen 25: 25) neqqaṛ: « Ma yella yefqir gma-k, yezzenz ayla-s, a d-yas bab n ufdu-ines i s-yettilin, ad ifdu ayen yezzenz gma-s ». Ma yella yefqir yiwen n wat Isṛail, yezzenz akal-is neɣ yezzenz iman-is d akli iwakken ad ixelleṣ aṭṭla-ines, ad as-tṛuḥ tlelli-ines meṛṛa, ur yezmir ara ad isellek iman-is, dagi i d-ittban wemkan n Bab n ufdu iwakken ad ixdem "Afdu".

Bab n ufdu d win i s-yettilin mliḥ s yidammen, cceɣl-is amezwaru d aḥader iwakken ad isellek mmi-s n tewsit-is, lameɛna lḥeqq-agi n ufdu ur yelli ara baṭel. Lqanun n Tira Iqedsen iban: iwakken ad ifdu win i s-yettilin, ilaq a d-iqerreb ad ixelleṣ azal meṛṛa deg wemkan-is. Ulac leslak s usirem kan, ulac asellek s tqerḥa kan; asellek yeḥwaǧ azal (lfedya) ara ixelleṣ ubdil.

Amedya ameqqran i wayagi d "Buɛaz" di tektabt n Ṛaɛut, ur nezmir ara ad ifdu ayla n Alimalik ad yazweǧ d Ṛaɛut s ubeccer n leḥmala-ines kan, lameɛna yella d lwaǧeb fell-as ad ixelleṣ azal zdat medden, ad yaɣ lḥeqq n ufdu s lqanun: « Yenna-d Bab n ufdu: ur zmireɣ ara ad fduɣ i yiman-iw iwakken ur ssexsaṛeɣ ara lwerṭ-inu. Fdu kecč i yiman-ik afdu-inu, axaṭer ur zmireɣ ara ad fduɣ » (Ṛaɛut 4: 6).

"Lfedya" (Padhah) akk-d lfeṭṭa n usebbel.. I wanwa ara yettwaxelles wazal? ↩

Awal aɛibri nniḍen d (Badah - Padhah), i yettuseqdacen i usellek n tjaṛa n waklan akk-d lexlaṣ n lfedya n yimenza akken i gweṣṣa Sidi Ṛebbi di (Tuffɣa 13: 13-15): « Mkul amenzu deg warraw-ik a t-tefduḍ... Imi Sidi Ṛebbi yenɣa mkul amenzu di tmurt n Maṣer, seg umenzu n wemdan armi d amenzu n lmal. Ɣef wayagi i zelluɣ i Sidi Ṛebbi... yerna fedduɣ mkul amenzu deg warraw-iw ». Awal-agi yessers lsas iǧehden: afdu di Tira Iqedsen mačči d "leslak" kan, lameɛna d asellek s lexlaṣ n lfedya.

Lameɛna, i wanwa tettwaxellaṣ lfedya-yagi? Lǧawab yella s wudem ibanen di lqanun n "lfeṭṭa n usebbel" (Tuffɣa 30: 11-16). Asmi i d-yettunefk lamer i wat Isṛail ad fken lfedya ɣef teṛwiḥin-nsen iwakken ad menɛen si lweba m'ara yettwaḥseb wegdud, yenna-d lqanun: « Ad yefk mkul yiwen lfedya n teṛwiḥt-is i Sidi Ṛebbi... at-tefkem lweɛda n Sidi Ṛebbi i usebbel ɣef teṛwiḥin-nwen ». Lmeɛna-yagi d ameqqran di tesnillawit; lfedya ur tettwaxellaṣ ara i ukli amesbaṭli, ur tettwaxellaṣ ara i Cciṭan (akken i ɣilen kra n yimusnawen mbeɛd), lameɛna tettwaxellaṣ i Sidi Ṛebbi s yiman-is, iwakken ad yettwaqbel zdat lḥeqq-ines amatu yerna d asebbel ɣef teṛwiḥt iwakken at-teslek si lḥisab n Ṛebbi. Ur nettaf ara di Lɛahd Aqdim meṛṛa afdu n tideț i gedṛan mbla lexlaṣ n wazal neɣ asers n ubdil (ama azal-nni d lfeṭṭa, neɣ d tudert n wesfel i d-yuzzlen d abdil iwakken ad yerḍi lḥeqq n Sidi Ṛebbi).

Imezura n teglizt: Yasuɛ d Bab n ufdu n tideț ↩

Lmeɛna-yagi n Tira Iqedsen: lḥaṣul n tilin n Bab n ufdu d win i s-yettilin di lǧețța iwakken ad ixelleṣ azal n waṭṭla, mačči d axlaq ajdid neɣ d axemmem ajdid ur tessin ara teglizt n yimezura, lameɛna d lsas i ɣef bnan yimezura imezwura n teglizt di ccerq lefhama-nsen i tuɣalin d aksum akk-d wumidag.

Aḥeqqi Atanasyus n Ṛṛusul, di tektabt-is yeddren i lebda "Tuɣalin n Wawal d aksum", yefhem mliḥ belli Sidi Ṛebbi ur yezmir ara ad ittu lḥeqq-ines yerna ad ikkes lḥisab n lmut s tḥunnint kan, akken daɣen amdan ur yezmir ara ad ixelleṣ azal n waṭṭlan-is. Tḥunnint d nețțat s yiman-is ara ixellṣen ayen i d-iṭṭalab lḥeqq-ines. D acu i gexdem "Lujus" (Awal) i gellan ɣer Sidi Ṛebbi, yellan d Sidi Ṛebbi s yiman-is? Yuɣal d "Bab n ufdu" fell-aɣ, yuɣal d win i ɣ-yettilin s weksum d yidammen iwakken ad yesɛu "lḥeqq n ufdu", iwakken ad yuɣal d abdil n lqanun i gzemren ad ixelleṣ azal.

Yenna-d Atanasyus:

"Axaṭer mi gwala "Lujus" (Awal) belli axsar amatu n yemdanen ur yezmir ara ad yettwakkes anagar s lmut, yerna d lmuḥal ad immet Wawal axaṭer ur yettmettat ara... yeddem i yiman-is lǧețța ur nxulef ara lǧețța-nneɣ... iwakken ad yuɣal d abdil deg wemkan n meṛṛa di lmut, a t-yefk i Ababat... ihi s usebbel n lǧețța-s d lfedya ɣef lǧețța n meṛṛa, ixelleṣ aṭṭla i gellan fell-aneɣ s lmut-is" ("Tuɣalin n Wawal d aksum" - Ixfawen 8 d 9).

Atanasyus dagi yettḥeqqiq s wudem n ccerq iqedsen belli Sidi Ṛebbi Awal "yeddem i yiman-is lǧețța ur nxulef ara lǧețța-nneɣ" (yuɣal-aɣ d Bab n ufdu d win i ɣ-yettilin) "iwakken ad yuɣal d abdil deg wemkan n meṛṛa" yerna ad ixdem cceɣl n usebbel deg wemkan-nneɣ "ihi s usebbel n lǧețța-s d lfedya... ixelleṣ aṭṭla i gellan fell-aneɣ s lmut-is".

Ulac leslak mbla lexlaṣ n wazal ↩

Yettaǧǧa-yaɣ Lɛahd Aqdim zdat n yiwet n tideț n tesnillawit ur nqebbel ara aɛiwez: nukkni d aklan yettwaṭṭalaben i lḥeqq n Sidi Ṛebbi imqeddes s lekmal, win ur nzemmir ara ad inkeṛ tideț-is n lḥeqq. Leslak ur yezmir ara a d-yedṛu s "ddukel n ṛṛuḥ" kan neɣ "tafat n ṛṛuḥ" akken tteṛden kra ad ssimẓiyen asebbel n Yasuɛ ass-agi. Asellek yeḥwaǧ "Bab n ufdu" i gzemren yerna yebɣan ad ibedd deg wemkan-nneɣ, ad yerfed taɛkumt n waṭṭla-nneɣ, yerna ad ixelleṣ azal s lekmal i lḥeqq n Sidi Ṛebbi. Tagi d tḥunnint n Sidi Ṛebbi akk-d tmella-s tamerkantit belli «... Mmi-s n bunadem ur d-yusi ara iwakken ad qedcen fell-as wiyaḍ, meɛna d nețța ara iqedcen fell-asen, yerna ad isebbel tudert-is iwakken ad isellek aṭas n yemdanen » (Marqus 10: 45).

Wagi d lsas iǧehden i ɣef ara yebnu Lɛahd Ajdid aweḥḥi-ines ameqqran: Yusa-d Bab n ufdu i nettraǧu, lameɛna d acu i d azal ara ixelleṣ? D wagi ara nwali deg umagrad i d-iteddun.

Tamawt: Tizrawt n yimeslayen di tezrawt-agi tewwezlan iwakken a d-tefk axemmem s wudem amatu yerna iban. Iwakken at-tezreweḍ s lqay, tzemreḍ at-tetbeɛeḍ imeslayen-agi di Tira Iqedsen.
