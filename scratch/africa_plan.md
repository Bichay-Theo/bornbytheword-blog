# خطة الترجمة الشاملة لمشروع أفريقيا
**Africa Translation Project - Master Action Plan (Final V1)**

## 1. الهدف الاستراتيجي الشامل
تأسيس خطة إنتاج مستدامة لترجمة **جميع** المقالات اللاهوتية لمدونة "شاء فولدنا بكلمة الحق" إلى اللغات الإفريقية الست (الأمهرية، السواحلية، القبائلية، التشلحيت، الطوارق، والماساي) بدقة لاهوتية مصلحة (Reformed)، مع النشر الأوتوماتيكي المتزامن عبر تليجرام. "سلسلة الفداء النيابي العقابي" ستكون المرحلة التأسيسية الانطلاقية.

## 2. الموارد والأدوات المعتمدة (The Engine)
*   **المرجع العقائدي المطلق:** القاموس الموحد الخماسي `pentalingual-master-reformed-glossary.json`.
*   **الدستور اللاهوتي (SKILL.md):** يحكم قيود التفسير المصلح ونبذ المصطلحات التوفيقية، مع التركيز على الاستباقية اللاهوتية (استخدام المبني للمجهول اللاهوتي Passivum Divinum).
*   **جمناي ويب (المراجع النهائي):** يُستخدم لتطبيق الرتوش الشكلية (التشكيل، الأرقام المشرقية) لتخفيف العبء الحاسوبي عن وكيل بيئة العمل (Agent).
*   **أتمتة النشر:** `scripts/telegram_publisher.py --lang <lang_code>`

---

## 3. آلية العمل القياسية المحدثة (The Dual-Step Workflow)
لأي مقال يتم اختياره للترجمة، سيتم تطبيق سير العمل المزدوج التالي لضمان أقصى كفاءة للموارد الحاسوبية واللاهوتية:

1.  **الصياغة اللاهوتية (Agent Phase):** 
    *   يقوم الوكيل الذكي (Antigravity) ببناء المسودة بتركيز حصري على **"العمق اللاهوتي والأسلوب المباشر"** الصالح للترجمة الإفريقية، واستخدام "المبني للمجهول اللاهوتي" في نصوص التبرير والاحتساب. 
    *   الالتزام الصارم بالعمود المخصص في "القاموس الخماسي".
2.  **المراجعة والتنسيق الشكلي (Gemini Web Phase):**
    *   يقوم المستخدم بتمرير النص عبر "جوهرة المراجع المُصلح" في جمناي ويب لإضافة الرتوش الشكلية (الأرقام المشرقية ١، ٢، وتشكيل فانديك الدقيق).
3.  **التوليد البرمجي (Markdown Generation):**
    *   إنشاء النسخ باللغات الخمس (`slug.am.md`, `slug.sw.md`...).
    *   ترجمة الواجهة الأمامية (Frontmatter) وربط الحواشي بدقة.
4.  **النشر الأوتوماتيكي (Automated Distribution):** إرسال النسخ المترجمة لقنوات التليجرام الست بشكل متزامن.

## 4. سياسة العرض في تليجرام (Telegram Visual Policy)
تم الاتفاق على نبذ استخدام أعلام الدول تجنباً لأي حساسية عرقية أو إقصاء جغرافي. عوضاً عن ذلك، تُعتمد الأسماء بصيغة:
**رمز تعبيري محايد (كتاب 📖) + [اسم اللغة] + ترجمة (شاء فولدنا بكلمة الحق):**
*   `📖 [Amharic] በእውነት ቃል አስቦ ወለደን።`
*   `📖 [Swahili] Kwa kupenda kwake mwenyewe alituzaa sisi kwa neno la kweli.`
*   `📖 [Taqbaylit] S lqesd n lebɣi-s, i ɣ-d-yefka talalit tajdit s wawal n tideț.`
*   `📖 [Tashelhit] S lqesd n lebɣi-ns, iskr aɣ-d talalit tamaynut s wawal n tideț.`
*   `📖 [Tamasheq] S-lqesd n-lebɣi n-Măssinăɣ, ikf-anaɣ-d talalit taynayt s-awal n-tideṭ.`
*   `📖 [Maa] Te nkaraki eyieunoto enye, etoiwuo Ninye iyiook to rorei loo sipat`
